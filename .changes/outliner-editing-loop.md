Outliner: the block-editing loop of Roam Research and Logseq (issue #104, milestone 1). Enter splits the block at the caret (at the start it inserts a block above, in a block with open children it makes the first child, on an empty nested last child it outdents); Shift+Enter is the line break. Backspace at the start merges into the previous block and Delete at the end merges the next one in. The arrow keys cross blocks, Up and Down keeping the caret's horizontal position. Tab, the move chords (Alt+Shift+Arrows or Mod+Shift+Arrows, now crossing into the neighbouring parent) and the fold chords (Mod+Up / Mod+Down) work while typing and keep the caret. A click enters a block at the clicked character. The editor grows with soft-wrapped text and entering a block shifts nothing. Each block has a bullet (ringed when folded), indent guides run under each parent, and the fold arrow shows on the hovered and the active row. An empty outline shows a placeholder that starts the first block (`placeholder`). The root is a `tree` of `treeitem` rows, one tab stop: a Tab into it does not select, Escape steps from the text to the block and then releases. **Changed behaviour:** `onChange` now fires on every keystroke (text is live; Escape no longer discards an edit). Outdent takes the following siblings along as children. Ctrl/Cmd+Enter no longer inserts a line break (Shift+Enter does). The row hover tint is gone and the chevrons are no longer primary. `Outliner` now forwards its ref and spreads HTML attributes onto the root, as API.md already said. `TreeChevron` takes a `tabIndex`.
