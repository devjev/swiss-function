Chat: a completion list under the editor and prompts in the editor's place, as a terminal agent has them. `completions` is asked for entries while a trigger is typed (`/` as the first character of the input for commands, `@` and `#` at the start of any word), synchronously or as a promise; the list shows five lines at a time in three columns (the cursor mark, the label, the description, dropped in a narrow chat), the arrows move it, Enter or Tab takes an entry, Escape closes it. An entry can be `partial` (a directory: the list asks again for what is inside) or act instead of writing (`onSelect`, for `/clear` or `/model`). `prompt` replaces the editor with a question: `select` (a list, scrolling past `rows`), `confirm` (starting on No), `input` (one line) or `custom` (the host's content), with key hints for a keyboard and a `[Cancel]` key for a finger; the draft in the editor is kept. `useChatPrompt()` asks from code and resolves with the answer (`await ui.confirm("Delete?")`). `ChatDrawer` forwards both. Refs #111.
