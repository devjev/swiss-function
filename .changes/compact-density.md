Compact density by default. The base metrics move from 16px text on a 24px unit to 14px on a 20px unit (`--sf-font-size-base`, `--sf-leading-base`; `sm` / `lg` type at 12 / 16px), so a control is 30px, a small one 20px and a large one 40px. `data-density="comfortable"` on any ancestor restores 16px on 24px for that subtree, and `data-density="compact"` switches a region back; floaters that portal to `<body>` take the root's density. New token `--sf-table-row-height`: the default body row of `DataTable` and `Explorer` (1.25 units = 25px compact, 1.5 units = 36px comfortable; `Explorer`'s comfortable default was 32px), measured at mount, with `rowHeight` still overriding per instance. The `--sf-space-N` ladder is now sixths of the unit and follows the density. Sizes that were rem or px literals follow the unit: `Checkbox`, `Radio` and `Switch` boxes, the `xs` / `sm` cell fonts of `DataTable` / `Explorer` / `TableInput`, the width floors of `Picker`, `Selector`, `Menu` and `Combobox` (8 units, was 12rem), `ColorPicker`, `Slider` length, `Widget` parameter fields, and the `TableInput` and column-filter virtual rows. `DataTable` `overflow: "wrap"` needs a `rowHeight` of 2.5 units for two lines (50px at the default density). New `lib/useCssPx` (`useCssPx`, `measureCssLength`, `DEFAULT_UNIT_PX`) for code that needs a token in px.
