Chat is restructured after a terminal agent's window (the pi coding agent) and set like a terminal: one monospace column on the unit grid, full-width entries one line apart, no bubbles and no right-aligned voice. The user's turn is a band in a tint of the accent, a reply sits on the page as terminal markdown, and under the transcript a dock stays put: the editor between two one-line rules with the `working` indicator set into the top one (`onInterrupt` on Escape), `aboveEditor` / `belowEditor` slots for the host, and `footer` status lines whose left side gives way and whose right side stays. `header` is a start banner that scrolls away. New parts: `tool` (a neutral band with the call line, the output cut to its last or first lines behind a marker, a closing note; Ctrl+O opens every block, a press on a marker one; a failure takes the danger rule) and `table` (a host's data as a real table drawn the way a terminal draws one, numbers in Swiss format ending their column, scrolling inside itself when wide). `ChatTable` and `ChatTool` are exported for a `renderPart` block of the host's own, and `ChatBlock` gains the `band` variant, now its default (`framed` and `plain` stay). Up and Down in an empty field walk the earlier messages. The send key shows only where the primary pointer is a finger (`sendKey`: `"auto"`, `true`, `false`). The jump-to-latest key is a reverse-video label. `Markdown` (and `StreamingTerminalText`) take `variant="terminal"`: one monospace size, headings told by weight and their `###`, fences kept and no box around code, `-` bullets, tables ruled like box drawing. `ChatDrawer` forwards the new props and its chat's working indicator follows `thinking`. **Breaking:** `messageStyle` is removed from `Chat` and `ChatDrawer` with the tape, box and squircle surfaces (retune the bands with `--sf-chat-user-bg` / `--sf-chat-block-bg`); the error part is a terminal error line with a `[Retry]` key in place of the glitch block; the choices and tree blocks lose their `select` / `tree` title bars; `ChatBlock` without a `variant` is a band (pass `variant="framed"` for the ruled panel); `borderColor` colours the editor's two rules, the field itself has no border. Refs #111.
