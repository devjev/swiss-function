`Outliner` shows a toolbar above the on-screen keyboard while a block is edited on a touch device (`toolbar`, `"auto"` by default): outdent, indent, move up, move down, task, undo, redo and a key that leaves the text, each running the command its keyboard chord runs without taking the focus. Six glyphs (`Indent`, `Outdent`, `Undo`, `Redo`, `Task`, `KeyboardHide`) and eight icon slots come with it.
